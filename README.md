# E-Ticaret Sepeti Kampanya ve İşlem Yönetim Sistemi (Konu D)

Bu proje, bir e-ticaret sistemindeki alışveriş sepeti ve sipariş süreçlerinin nesne yönelimli tasarım örüntüleri kullanılarak esnek bir mimariye dönüştürülmesini içerir.

## Uygulanan Tasarım Örüntüleri (Patterns)
1. **Factory Method (Creational):** İndirim nesnelerinin yaratılma sorumluluğunu sepetten ayırır.
2. **Decorator (Structural):** Koda dokunmadan kargo sigortası veya hediye paketi gibi ek hizmetleri dinamik ekler.
3. **Facade (Structural):** Stok, Ödeme ve Kargo alt sistem karmaşasını tek merkezden yönetir.
4. **Observer (Behavioral):** Sipariş bittiğinde SMS ve E-posta bildirimlerini gevşek bağlı tetikler.
